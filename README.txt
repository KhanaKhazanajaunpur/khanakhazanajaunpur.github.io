FREE PUBLISHING:
Option 1 — GitHub Pages
1. Create a free account at github.com.
2. Create a new public repository, e.g. khana-khazana-website.
3. Upload every file/folder from this package.
4. Repository Settings → Pages → Deploy from branch → main → /root → Save.
5. GitHub will give you a free website address.

Option 2 — Netlify
1. Create a free account at netlify.com.
2. Use Add new site → Deploy manually.
3. Upload the whole website folder (or unzip this package first).
4. Netlify will give you a free website address.
